# Video Script Workflow

From a rough idea to a script you can record in one sitting.

## The problem

Most video ideas stall between the idea and the script. Written text read aloud sounds stiff, and a blank page makes the first line hard.

## What this does

A prompt that turns a rough idea into a script written for speaking, with the hook, the on-screen text and the cut points marked.

## How to use it

1. Fill in the idea, the viewer and the length in `prompts/idea-to-script.md`.
2. Run it, then read the script aloud once.
3. Mark every line that trips your tongue and rewrite it by hand.
